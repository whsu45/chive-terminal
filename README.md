# 📈 台指期每日/每週走勢預測儀表板 (Taiwan Futures Forecast Dashboard)

本專案利用 Python 自動爬取台灣期貨交易所（TAIFEX）官方數據，計算夜盤三大關鍵指標，並透過 **GitHub Actions** 與 **GitHub Pages** 實現每日自動更新與靜態網站發布。

---

## 🔍 分析指標與劇本邏輯

### 1. 三大關鍵指標
* **夜盤漲跌點數**：反映美股時段消息面影響，±300 點為強烈預期門檻。
* **夜盤量佔比**：`夜盤成交量 / (前日日盤成交量 + 夜盤成交量)`
  * `< 30%`：訊號較弱，參考價值較低。
  * `> 40%`：訊號極強，有大量主力/法人資金參與。
* **外資多空淨額**：觀察外資在夜盤的淨口數，±1,000 口為態度明確門檻。

### 2. 四種實戰開盤劇本

| 劇本 | 夜盤漲跌 | 外資多空淨額 | 預期走勢 |
| :--- | :--- | :--- | :--- |
| **劇本一** | 上漲 | 正數（看多） | 漲勢紮實，開盤後容易持續往上走。 |
| **劇本二** | 上漲 | 負數（看空） | 力道不足，容易出現開高走低，隨後殺下來。 |
| **劇本三** | 下跌 | 負數（看空） | 跌勢延續，不建議貿然抄底，因為可能會持續下跌。 |
| **劇本四** | 下跌 | 正數（看多） | 開低反彈，外資未跟著殺盤，反彈機率高。 |

---

## ⏰ 自動化更新時間 (GitHub Actions Schedule)

GitHub Actions 會在台灣時間每週一至週五開盤前執行兩次（備援機制）：
* **第一次：07:30 AM (TST)**
* **第二次：08:30 AM (TST)**

若當天期交所資料尚未準備好或休市，系統會自動在儀表板顯示 **`NA`**，避免出現錯誤訊息。

---

## 🚀 部署設定 (GitHub Pages Setup)

1. 將本專案推送到 GitHub Repository。
2. 前往 **Settings** -> **Pages**。
3. 將 **Build and deployment > Source** 切換為 **`GitHub Actions`**。
4. 到 **Actions** 頁籤點擊 **Update Taiwan Futures Forecast Page** -> **Run workflow** 即可完成首次發布。
